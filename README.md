## Пет-проекты

|---|---|---|---|---|
| 1 | [Анализ отзывов о ночных клубах Москвы](https://github.com/natlyvvva/clubs-reviews-analysis) | Сбор ~1 600 отзывов о 25 клубах из Google Maps через SerpApi. EDA, проверка смещения выборки относительно официального рейтинга, доли негатива по клубам с интервалами Уилсона. Multi-label классификация жалоб по темам с помощью LLM (Gemini 2.5 Flash), валидация на ручной разметке 149 отзывов (Micro F1 = 0.79). Цель — понять, какие проблемы сильнее всего снижают оценку заведения | Завершен | Python, pandas, statsmodels, scikit-learn, OpenAI SDK (Gemini 2.5 Flash), SerpApi, matplotlib, seaborn |
