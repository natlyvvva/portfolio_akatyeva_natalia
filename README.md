## Учебные проекты
| # | Название проекта | Описание проекта | Статус | Стек |
|:---:|---|---|:---:|---|
| 1 | [Автоматизация обработки заказов для Foppa GmbH](https://github.com/natlyvvva/foppa-order-processing) | Прототип системы, превращающей заказы из WhatsApp — текст, фото рукописных списков, сканы PDF — в позиции для ERP оптового поставщика. Мультимодальное извлечение через Gemini 2.5 Flash, трёхстадийный матчинг по каталогу из 6 460 товаров: шаблон клиента, нечёткое сравнение rapidfuzz с нормализацией немецких составных слов, фолбэк по полному каталогу. Позиции ниже порога уверенности уходят на проверку человеку в веб-интерфейсе. FastAPI-приложение, покрытое pytest | Завершен | Python, rapidfuzz, Google Gemini API |
| 2 | [Возобновляемая энергия и цены на электроэнергию в Австрии](https://github.com/natlyvvva/austria-electricity-econometrics) | Эконометрика day-ahead рынка Австрии на 2 312 дневных наблюдениях (2020–2026) по данным ENTSO-E и Copernicus. База в PostgreSQL из трёх схем, merit-order регрессии в пяти спецификациях, SARIMAX для прогноза цены, семейство GARCH для волатильности. Рост остаточной нагрузки на 1 000 МВт связан с ценой выше на 16,5 EUR/MWh, в кризис 2022 года — на 32; SARIMAX обходит наивный прогноз на 30-дневном окне (RMSE −26%, MAE −32%); волатильность устойчиво повышает только доля солнца | Завершен | PostgreSQL, R, tidyverse, forecast, rugarch |
